# Employee Management System (Java)

A console-based Employee Management System developed in Java as part of a Higher Diploma in Computer Science coursework project.

This application demonstrates the implementation of fundamental data structures and algorithms including:

- Insertion Sort
- Recursive Binary Search
- Binary Trees
- Breadth-First Search (BFS)
- File Handling
- Object-Oriented Programming (OOP)

---

## Features

### 1. Sort Employee Records
- Reads employee data from a `.txt` file
- Sorts employee names alphabetically using **Insertion Sort**
- Displays the first 20 sorted names

### 2. Search Employees
- Uses **Recursive Binary Search**
- Searches employees by name
- Displays:
  - Employee Name
  - Manager
  - Position
  - Department

### 3. Add Employee Records
- Allows adding new employees directly into the text file
- Supports:
  - Operative roles
  - Manager roles
- Assigns managers and departments through menu selections

### 4. Binary Tree Generation
- Builds a binary tree using employee records
- Uses **Level-Order Insertion**
- Traverses the tree using **Breadth-First Search (BFS)**
- Displays:
  - Employee hierarchy
  - Total nodes
  - Tree height
